# Импорт дверной фурнитуры из Китая — расчёт себестоимости

**Калькулятор:** `index.html` — выбираете товар, вписываете цену фабрики за 1 шт, получаете себестоимость в Бишкеке (сом и $) с расшифровкой всех расходов. Ставка пошлины подставляется по коду ТН ВЭД ЕАЭС. Работает с телефона.

**Модель партии:** `Импорт_фурнитуры_Китай_расчёт.xlsx` — заказ на одну фуру (20 позиций, ~19,5 т), таможенные платежи, логистика, итог.

## Что учитывается
- Доставка фурой ($9 000), делится по весу
- Ввозная пошлина по ЕТТ ЕАЭС (8302 41 — 10%, 8302 10 петли — 0%, 8301 40 замки — 12%, 8301 60 цилиндры — 15%, 8302 60 доводчики — 10%)
- НДС при импорте 12%, таможенный сбор 0,4%
- Страховка, банк, агент в Китае, брокер/СВХ, резерв

Ставки и цены — ориентир; коды подтвердите у брокера перед заказом.

`build.py` + `items.py` пересобирают Excel-файл.
